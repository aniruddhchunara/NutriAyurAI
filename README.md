# 🥗 NutriAyurAI

A Comprehensive Cloud-Based Practice Management & Nutrient Analysis Software for Ayurvedic Dietitians.

## 📌 Project Overview

NutriAyurAI is a Python-based healthcare analytics application that helps manage patient records, calculate BMI, generate reports, and analyze patient health data using SQLite, Pandas, and Matplotlib.

This project is being developed as a complete learning project to master Python, Object-Oriented Programming, SQL, Data Analytics, and Machine Learning.

# ▶️ How to Run

Clone the repository

```bash
git clone https://github.com/aniruddhchunara/NutriAyurAI.git
```

Go to the project folder

```bash
cd NutriAyurAI
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the project

```bash
python main.py
```

Run Analytics Dashboard

```bash
python -m analytics.dashboard
```
